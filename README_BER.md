**_Cocos2d-x_** (framework open source):  
Since 2011, Cocos2d-x has provided users with an open-source, stable, and easy-to-customize cross-platform game solution. The engine provides three programming language interfaces: C++, Lua, and JavaScript. Cross-platform support includes smartphones such as iOS, Android, and others, Windows, Mac, and other desktop operating systems, along with web browsers Chrome, Safari, IE, and other HTML5 browsers. Cross-platform will never be a hindrance for developers.
